# License status

**No open-source license has been chosen for VoiceWire yet.** This is
intentional, not an oversight.

Until a license is added:

- All rights to this codebase are reserved by its contributors.
- Do not treat the absence of a `LICENSE` file as permission to use,
  redistribute, or relicense this code.
- `pyproject.toml` intentionally omits a `license` classifier for the same
  reason.

This status must be explicitly resolved — by adding a `LICENSE` file and
updating `pyproject.toml` and this document — before any public release or
package publish (e.g. to PyPI).
